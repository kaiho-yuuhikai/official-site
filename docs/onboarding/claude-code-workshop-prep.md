## STEP 1: Claude のアカウントを作り、有料プランに入る（約10分）

Claude Code を使うには、Claude の**有料プラン**が必要です。無料プランでは動きません。

1. https://claude.ai/ を開く
2. 「Sign up」からアカウントを作る（Googleアカウントでのログインが一番かんたんです）
3. ログイン後、左下の**自分の名前 → Settings（設定）→ Plans（プラン）**へ進む
4. **Pro プラン**（月20ドル・約3,000円）を選んで契約する

> **費用について**: 雄飛会からの補助はありません。各自でのご契約をお願いします（8/11 上間さん決定）。
> Claude は資料作成・文章の下書き・表計算など、サイト更新以外にも幅広く使えるツールです。
> 合わない場合は**いつでも解約できます**（次回更新日以降の請求は止まります）。

**✅ ここまでのゴール**: claude.ai にログインでき、設定画面で「Pro」と表示されている

## STEP 2: GitHub のアカウントを作り、ユーザー名を報告する（約5分）

雄飛会のホームページのデータは「GitHub」という場所に保管されています。
**ここへの参加権限がないと、直したページを公開できません。**

1. https://github.com/signup を開く
2. メールアドレス・パスワード・**ユーザー名**を決めて登録する
   - ユーザー名は半角英数字です（例: `uema-shoko`）
   - 後で使うので**メモしておいてください**
3. 登録したメールに届く確認コードを入力して完了
4. **決めたユーザー名を、勉強会のグループに投稿してください**

> 神谷が権限を付与します。**当日の朝までに投稿がないと、当日ホームページを公開できません。**
> 権限が付くと GitHub からの招待メールが届くので、メール内の緑のボタン（Accept invitation）を押してください。

**✅ ここまでのゴール**: GitHub にログインできる／ユーザー名をグループに投稿した／招待メールを承諾した

## STEP 3: 必要なソフトを1行のコピペで入れる（約20分・ほぼ待ち時間）

ここが一番「難しそう」に見えますが、**やることは1行の貼り付けだけ**です。
下の1行を貼ると、必要なもの（Node.js・Git・Claude Code など）が全部自動で入り、
雄飛会サイトのデータもパソコンに複製されます。

### Mac の場合

1. 「ターミナル」を開く（画面右上の🔍虫めがねをクリック →「ターミナル」と入力 → Enter）
2. 黒い画面（または白い画面）に、下の1行を貼り付けて Enter

```bash
curl -fsSL https://raw.githubusercontent.com/kaiho-yuuhikai/official-site/main/scripts/bootstrap.sh | bash
```

3. 途中で**パソコンのパスワード**を聞かれたら入力してください（画面に文字は出ませんが、入力できています）
4. 最後に**お名前とメールアドレス**を聞かれるので入力

### Windows の場合

1. スタートメニューで「PowerShell」と検索して開く
2. 下の1行を貼り付けて Enter

```powershell
irm https://raw.githubusercontent.com/kaiho-yuuhikai/official-site/main/scripts/bootstrap.ps1 | iex
```

3. 最後に**お名前とメールアドレス**を聞かれるので入力

> **「WinGet not found」と出て止まったら**: Microsoft Store から「アプリ インストーラー」を入れてから、
> もう一度1行を貼り付けてください → https://apps.microsoft.com/detail/9NBLGGH4NNS1

### 終わるとこう表示されます

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  セットアップ完了！
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**✅ ここまでのゴール**: 「セットアップ完了！」が表示された

## STEP 4: 2つのログインをすませる（約10分）

ソフトを入れただけでは使えません。**Claude と GitHub、2つのログイン**が必要です。

### 4-1. GitHub にログイン

ターミナル（Windows は PowerShell）に、そのまま次を貼り付けて Enter：

```bash
gh auth login
```

矢印キーで選んで Enter を押していきます。

| 聞かれること | 選ぶもの |
|:--|:--|
| What account do you want to log into? | **GitHub.com** |
| What is your preferred protocol...? | **HTTPS** |
| Authenticate Git with your GitHub credentials? | **Yes** |
| How would you like to authenticate? | **Login with a web browser** |

画面に**8文字のコード**（例: `A1B2-C3D4`）が出ます。これをコピーして Enter を押すと
ブラウザが開くので、**コードを貼り付け → Authorize** で完了です。

### 4-2. Claude Code にログイン

続けて、次の2行を1行ずつ貼り付けて Enter：

```bash
cd ~/official-site
claude
```

初回はブラウザが開くので、**STEP 1 で作った Claude アカウント**でログインし、
表示されるコードを画面の指示どおりに貼り付けてください。

**✅ ここまでのゴール**: `claude` と打つと Claude Code の画面（枠で囲まれたロゴ）が出る

### よくあるつまずき

| 症状 | 対処 |
|:--|:--|
| `command not found: brew` / `claude` が見つからない | ターミナルを一度閉じて開き直してから、もう一度お試しください |
| Windows で「スクリプトの実行が無効」と出る | PowerShell に `Set-ExecutionPolicy -Scope Process RemoteSigned` を貼って Enter → もう一度1行を実行 |

| 何をやっているか分からなくなった | STEP 3 の1行をもう一度貼り付けてください。**何度実行しても壊れません** |
